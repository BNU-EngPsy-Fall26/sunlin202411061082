# 果品检验局 · Apple Inspection Lab

工程心理学「信号检测论交互式实验网站」个人作业。纯前端实现，打开 `index.html` 即可运行，不需要后端、安装或网络连接。

## 运行方法

1. 下载本仓库（GitHub → Code → Download ZIP），并解压。
2. 双击 `index.html`，使用 Chrome、Edge、Safari 等现代浏览器打开。
3. 设置难度、试次数、发霉概率和观察时间，点击「开始检验」。
4. 点击「展示苹果」，短暂观察后选择「合格」或「发霉」。
5. 完成全部试次后查看混淆矩阵、SDT 指标、ROC 曲线、概念实验室及多局排行榜。可导出逐题与多局 CSV 数据。

## 实验设计

- **场景**：苹果质检员分辨发霉苹果与正常苹果。
- **信号 S**：出现霉斑或腐坏性干瘪褶皱（包括两者兼有）；**噪音 N**：正常果皮、泥土、擦痕、压纹与天然皮孔。
- **默认先验概率**：P(S) = 0.5，可调节 0.1–0.7。
- **试次数**：20、40、100 次。每批同时包含 S/N 两类刺激且随机排列。
- **刺激曝光**：默认 500 毫秒，可调节 300–1200 毫秒；每题仅显示一次，不提供逐题反馈。
- **难度**：5 档，通过霉斑大小、纤维特征、干瘪皱纹的显著程度和表皮干扰数量变化控制。注意这是一种视觉难度调节，不是直接给定某个理论 d′ 数值；经验 d′ 要根据玩家数据估计。

发霉/腐坏刺激随机采用霉斑型、干瘪褶皱型及混合型；CSV 数据中可查看每题外观类型。

## SDT 计算

令 H（击中）、M（漏报）、FA（误报）、CR（正确拒斥）为相应次数。

- 击中率：P(H) = H / (H + M)
- 误报率：P(FA) = FA / (FA + CR)
- 准确率：(H + CR) / (H + M + FA + CR)

为避免 z(0) 或 z(1) 无穷大，使用 log-linear 校正：

- PH* = (H + 0.5) / (H + M + 1)
- PFA* = (FA + 0.5) / (FA + CR + 1)
- d′ = z(PH*) − z(PFA*)
- c = −[z(PH*) + z(PFA*)] / 2
- β = exp(d′ × c)

图中实际数据点使用未校正的 P(H)/P(FA)，模型 ROC 曲线则使用校正后的经验 d′ 推算：P(H) = Φ[Φ⁻¹(P(FA)) + d′]。ROC 为拟合的可视化曲线，并非多个真实判断标准的实验观测曲线。

## 加分项（完整覆盖）

1. **交互式概念可视化**：结果页「SDT 概念实验室」有两支滑块。调整 d′ 时，正态信号/噪音分布间距及 ROC 曲线同步更新；调整 c 时，判断阈值位置及 ROC 工作点同步更新，同时计算模型 P(H)、P(FA)。点击「使用我的本局 d′ / c」可将实验估计值映射到教学模拟器。理论模型与实测数据分开标注。
2. **多局数据对比及排行榜**：每批结束后自动记录 试次数、难度、观察时间、先验概率、H/M/FA/CR、准确率、d′、c；本机浏览器 `localStorage` 持久保存最近 100 局，排行榜按 d′ 排序；支持导出多局 CSV、清空记录。
3. **美观、场景代入感**：苹果质检局世界观、传送带、限时观察、多类型腐坏苹果（霉斑／干瘪褶皱／混合）与泥土、擦痕、压纹干扰，统一配色和响应式界面。

**课堂演示建议**：先做一局 20 题并解释结果；拖动概念实验室两支滑块，演示 d′ 和 c 的独立作用；再做第二局，查看排行榜和历史比较。

历史数据存放在当前浏览器本地，不会上传服务器；不同浏览器/无痕窗口的记录不共享。浏览器禁用本地存储时只能临时保留数据。不同设置下排行榜的 d′ 不代表严格公平的能力排名。
