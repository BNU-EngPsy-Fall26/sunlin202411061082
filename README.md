## 1. 项目介绍与运行方式

本项目将两个经典范式改编成同一个可交互网站中的小游戏：W6“目标搜寻行动”和W8“城市配送行动”。前者比较特征搜索与联合搜索，并增加可靠区域提示；后者比较北向上与航向上地图，并增加以骑手为中心的方向参照。两项改进都实际收集了数据。

项目属于经典范式的情境化改编，并非原论文全部实验程序的逐项直接复刻。分析比较效应方向及任务机制，不把网页反应时与原论文的绝对毫秒数直接等同。

采用HTML、CSS与JavaScript实现；已核对的1.3.1单文件版本把样式和脚本放在`index.html`中。下载或clone课程仓库后，在电脑浏览器打开`index.html`即可运行，无需后端或安装依赖。请使用鼠标和实体键盘，窗口至少850×580。课程接口上传需要网络；离线运行时可以保留本地数据并导出。

- 流程：任务说明 → 匿名编号与知情同意 → 6次练习 → 正式任务 → 个人结果与数据提交。
- 射击采用鼠标点击；导航采用←、↑、→表示骑手视角的左转、直行和右转。
- 程序使用`performance.now()`计时，准备和提示阶段不计入反应时。
- 快速体验各3次，不纳入正式分析。被试可随时退出。
- 数据先保存在本浏览器；完成后手动确认提交课程平台。不要在代码或仓库公开下载密钥。

## 2. 实验一：目标搜寻行动（W6视觉搜索）

### 2.1 经典依据与研究问题

参考Treisman与Gelade（1980）的特征整合理论及视觉搜索范式，考察搜索类型和项目数量如何影响表现。单一颜色即可区分的目标通常较容易找到；当目标需要同时依据颜色和形状区分时，搜索可能更依赖注意分配。本项目进一步检验：提前给出可靠的目标所在半区，是否能减少搜索耗时。

### 2.2 设计、材料与改进

采用2（特征/联合搜索）×3（8/16/24个项目）×2（中性/有效区域提示）的被试内设计，共12个组合，每组合5次，共60次正式试次。

目标始终为橙色圆形，且每轮都有目标。特征搜索中干扰项为蓝色圆形；联合搜索中干扰项由蓝色圆形与橙色方形构成。被试点击中央准星后，先出现500 ms提示，再呈现搜索阵列；第一次点击即记为反应，点击干扰项或空白处计错，正式试次时限8秒。

新增条件为**有效区域提示**：仅标记目标所在的左半区或右半区，目标一定出现在该区；中性提示同时标记两侧。该操作意在缩小需要搜索的范围，而非直接指出目标。

程序随机排列试次，并对目标位置及左右半区作约束平衡；1.3.1源码使用会话相关随机种子，避免相同编号每次重复同一射击序列。项目数量也会改变视觉密度，因此不能把所有数量效应都归因于单一认知过程。

因变量为正确率、正确反应时及搜索斜率（ms/项目）。每15次正式试次提供休息机会。

### 2.3 实验预测（沿用前期方案）

1. 中性提示下，联合搜索比特征搜索耗时更长，且搜索斜率更大。
2. 有效区域提示可能缩短反应时间，其收益可能在联合搜索中更大。

以上预测沿用前期方案，在本README中与收数后的结果合并呈现，未根据结果反向修改预测方向。历史提交时间以课程仓库的实际commit记录为准。

## 3. 实验二：城市配送行动（W8空间认知）

### 3.1 经典依据与研究问题

参考Aretz（1991）的电子地图显示研究，比较北向上与航向上显示对即时转向判断的影响。原研究讨论了自我中心判断与认知地图学习之间的不同要求。本任务只检验骑手视角的即时转向，不测量路线记忆或认知地图形成。

### 3.2 设计、材料与改进

采用3种显示方式×4种骑手朝向（北0°、东90°、南180°、西270°）的被试内设计，共12个组合，每组合6次，共72次正式试次。每组合左转、直行和右转各2次。

| 显示方式     | 操作定义                       |
| -------- | -------------------------- |
| 北向上      | 地图北方固定朝屏幕上方，骑手朝向改变         |
| 航向上      | 地图根据骑手朝向旋转，使骑手前方朝屏幕上方      |
| 北向上＋方向参照 | 保留北向上地图，增加以骑手为中心的左、前、右方向标记 |

被试按空格准备，地图与路线出现后用方向键作答。判断基于骑手视角，而不是屏幕的左右。正式时限10秒，每12次可休息。显示方式按区组呈现；源码按匿名编号的哈希值从6种模式顺序中选取一种，各区组内试次随机排列。**这不等于实际15人的顺序已严格均衡。**

新增方向参照旨在减少“地图方向→骑手方向”的转换负担。这是本项目自己的改进，不能等同于原论文的visual momentum显示。

### 3.3 实验预测（沿用前期方案）

1. 即时转向任务中，航向上可能比北向上更快或更准确。
2. 北向上增加方向参照可能改善表现，尤其在骑手朝向与地图方向不一致时。

以上为前期方案中的预测。结果部分另外报告朝南条件的探索性比较，与整体方向参照收益的预测分开解释。

| ------- | ------:| ------:| -------:|

| 总体正确率   | 94.33% | 92.69% | —       |

导出文件中无程序标记的无效试次、超时、缺失反应时或反应时低于150 ms的记录。这仅描述文件内容，不能据此断言收数过程中不存在其他干扰。未剔除任何被试，包括表现较低者；未根据结果方向增删数据。

### 4.3 清理与汇总规则

- 正确率：正确试次数/有效正式试次数，错误反应保留在分母中。
- 反应时：仅保留正确、非超时、非无效且RT≥150 ms的正式试次；不依据显著性追加截尾规则。
- 先计算每名被试每个完整条件组合的正确RT中位数，再在相关组合间等权平均，最后计算15人的均值和标准差。表中的“平均RT”因此是**被试条件中位数的汇总**，不是把所有试次混合计算的均值。
- 搜索斜率：对每名被试各搜索类型×提示条件的8、16、24项目条件中位数作直线拟合，再汇总个人斜率。
- 条件对比：以15名被试为独立单位作双侧配对t检验，df=14；报告均值差、95%置信区间、配对效应量d_z（个人差值均值/差值标准差）。不把1,980个试次当作独立样本。
- 本次收数后整理的10项推断比较统一作Holm校正，同时保留原始p值。95%置信区间为未作多重比较调整的区间，可能与校正后p值给出不同判断。
- 小样本、每条件试次较少，且正确率存在接近上限的情况；t检验属于探索性近似，结论以效应估计和不确定性为主。本报告没有宣称完成全因子重复测量方差分析。

## 5. 实验一结果

### 5.1 描述统计

| 搜索类型 | 提示   | 平均RT（ms） | 被试间SD（ms） | 正确率    |
| ---- | ---- | --------:| ---------:| ------:|
| 特征搜索 | 中性   | 895.44   | 244.44    | 94.22% |
| 特征搜索 | 有效区域 | 844.53   | 225.19    | 94.67% |
| 联合搜索 | 中性   | 1077.27  | 251.43    | 94.67% |
| 联合搜索 | 有效区域 | 1005.16  | 234.64    | 93.78% |

### 5.2 项目数量与搜索斜率

| 条件      | 8项目RT  | 16项目RT  | 24项目RT  | 平均搜索斜率（ms/项目） |
| ------- | ------:| -------:| -------:| -------------:|
| 特征＋中性   | 882.84 | 886.03  | 917.46  | 2.16          |
| 特征＋有效区域 | 882.72 | 827.36  | 823.49  | -3.70         |
| 联合＋中性   | 991.75 | 1079.51 | 1160.56 | 10.55         |
| 联合＋有效区域 | 943.28 | 1013.59 | 1058.60 | 7.21          |

中性提示下，联合搜索比特征搜索平均慢181.83 ms，15名被试的差值均为正。联合搜索斜率为10.55 ms/项目，特征搜索为2.16 ms/项目，斜率差为8.39 ms/项目。这两项差异经Holm校正后仍显著，结果方向符合经典范式中联合搜索具有更大项目数量成本的预期。

有效提示使特征搜索和联合搜索分别平均缩短50.92 ms和72.12 ms，各有11/15名被试表现出加快。原始p分别为.022和.010，但10项比较统一校正后分别为.110和.060。因此，区域提示表现出有利趋势，但不能在本次多重比较标准下断言其效果已得到稳健验证。

“联合搜索的提示收益更大”也未获明确支持：两类提示收益相差21.20 ms，95% CI [−27.62, 70.02]，原始p=.367。不能因为一类收益数值较大就认定存在交互作用。

特征搜索有效提示下出现小幅负斜率（−3.70 ms/项目），不应解释为“项目越多必然越容易”。较少试次、位置与运动时间差异、抽样波动都可能影响斜率估计。联合搜索的提示条件正确率略低于中性条件（93.78% vs. 94.67%），因此速度改善还应结合准确性考察；这里未对射击正确率单独作显著性检验。

### 6.1 显示方式比较

| 显示方式     | 平均RT（ms） | 被试间SD（ms） | 正确率    |
| -------- | --------:| ---------:| ------:|
| 北向上      | 1055.19  | 450.06    | 88.61% |
| 航向上      | 622.10   | 185.48    | 99.17% |
| 北向上＋方向参照 | 995.64   | 314.20    | 90.28% |

航向上比北向上平均快433.09 ms，15名被试均表现出该方向的差异；正确率高10.56个百分点。两项比较经Holm校正后仍显著。速度和准确性方向一致，未表现为“以更多错误换取更快反应”。

## 8. 与原研究对照、讨论及局限

### 8.1 与经典研究的关系

视觉搜索方面，本项目发现中性条件下联合搜索更慢、数量成本更大，与Treisman和Gelade（1980）的经典理论预期方向一致。但本任务目标始终存在，要求鼠标定位点击，包含视觉搜索、反应选择和鼠标运动，不能将RT全部解释为纯注意加工，更不能据此声称完整复现了原文全部结果。

地图显示方面，即时转向中航向上的优势，与Aretz（1991）关于自我中心参照兼容性的解释一致。原研究同时涉及北向上在认知地图形成方面的优势，本项目没有测量该能力，因此不能推论航向上对所有导航任务都更好。本项目没有提取原论文逐项数值进行同尺度效应量对照；目前对照限于机制与效应方向。

### 8.2 对改进方案的反思

区域提示可能减少候选范围，但本样本中收益尚不足以在统一多重比较控制下形成明确结论。导航方向参照未出现稳定整体收益，可能是参照信息本身需要阅读与转换，也可能仅在方向冲突较大的情境下有用。这些解释是待检验的推测，本研究未测量眼动或认知负荷，不能把推测写成已证实机制。

后续可在固定总时长下减少因子水平、增加每个关键条件的重复次数；也可针对朝南等困难朝向单独设计新研究，但应在新一轮收数前固定预测。不能依据本轮结果修改原数据或将探索性发现包装为事前假设。

### 8.3 研究局限

1. 样本与推广限制。15人超过最低5人的人数要求，但仍为小样本；本数据不能支持对一般人群稳定推广。后续需要扩大样本，检验结果的可重复性。
2. **顺序控制有限。**多数可追溯记录为先射击后导航，两实验顺序不能宣称严格平衡。模式顺序由哈希选择也不保证样本内均衡；练习、疲劳和区组顺序可能影响结果。
3. **设备与计时限制。**使用浏览器高分辨率计时，但屏幕刷新、输入设备和不同电脑性能仍可能造成误差。
4. **少量试次与正确率上限。**每个组合只有5或6次，错误率变化步长较大；航向上正确率接近100%，其分布不完全符合连续正态变量假设，相关t检验应谨慎解读。

## 9. 数据字段与复核

平台外层`experiment`取值为`visual_search_cue`或`map_orientation_aid`；外层`condition=within_subject`仅表示被试内研究，**不是具体实验条件**。具体条件读取`cond`或`trial.condition`。`trial.experiment`区分`fps/nav`，`rt`单位为ms，`correct/timeout/invalid/completed`是布尔文本，读取时需同时识别`True/False`。被试编号按字符串处理，避免丢失前导零。

用于复核的计算顺序：保留原始CSV → 应用已确认的编号映射 → 核对每人12个完整条件 → 按规则提取RT → 计算个人条件中位数及正确率 → 个人条件间配对 → 汇总均值差、置信区间、效应量及p值。原始数据和下载密钥应分别保管，公开仓库不得放入下载密钥。

```python
import pandas as pd,numpy as np,json
from scipy import stats
p='hw2_J5J9UJ_2026-11-08_175034.csv'
d=pd.read_csv(p,dtype=str).fillna('');d['pid']=d.participant.replace({'0408':'0648','P04':'ni'});d.rt=pd.to_numeric(d.rt);d['ok']=d.correct.str.lower().eq('true');d['valid']=~d.invalid.str.lower().eq('true');d['use']=d.ok&d.valid&~d.timeout.str.lower().eq('true')&(d.rt>=150)
c=d.groupby(['pid','trial.experiment','cond']).agg(rt=('rt',lambda x:x[d.loc[x.index,'use']].median()),acc=('ok','mean')).reset_index()
f=c[c['trial.experiment']=='fps'].copy();f[['type','size','cue']]=f.cond.str.split('_',expand=True);f['size']=f['size'].astype(int)
n=c[c['trial.experiment']=='nav'].copy();n[['mode','heading']]=n.cond.str.rsplit('_',n=1,expand=True)
def describe(x):return {'n':len(x),'mean':x.mean(),'sd':x.std(ddof=1)}
res={'fps':{},'nav':{},'contrasts':{},'slopes':{}}
for key,g in f.groupby(['type','cue']):
 u=g.groupby('pid')[['rt','acc']].mean();res['fps']['_'.join(key)]={'rt':describe(u.rt),'acc':describe(u.acc*100)}
for key,g in n.groupby('mode'):
 u=g.groupby('pid')[['rt','acc']].mean();res['nav'][key]={'rt':describe(u.rt),'acc':describe(u.acc*100)}
def contrast(name,a,b):
 x=(a-b).dropna();se=stats.sem(x);t,p=stats.ttest_1samp(x,0);ci=stats.t.interval(.95,len(x)-1,loc=x.mean(),scale=se);res['contrasts'][name]={'n':len(x),'diff':x.mean(),'sd':x.std(ddof=1),'t':t,'p':p,'ci':list(ci),'dz':x.mean()/x.std(ddof=1),'positive':int((x>0).sum())}
fpt=f.groupby(['pid','type','cue']).rt.mean().unstack(['type','cue']);npt=n.groupby(['pid','mode']).rt.mean().unstack('mode')
contrast('fps_neutral_conj_minus_feature',fpt['conjunction','neutral'],fpt['feature','neutral'])
for typ in ['feature','conjunction']:contrast('fps_cue_'+typ,fpt[typ,'neutral'],fpt[typ,'valid'])
contrast('fps_cue_interaction',fpt['conjunction','neutral']-fpt['conjunction','valid'],fpt['feature','neutral']-fpt['feature','valid'])
sl=f.groupby(['pid','type','cue']).apply(lambda g:np.polyfit(g['size'],g.rt,1)[0],include_groups=False).unstack(['type','cue'])
for col in sl:res['slopes']['_'.join(col)]=describe(sl[col])
contrast('fps_slope_neutral',sl['conjunction','neutral'],sl['feature','neutral'])
contrast('nav_north_minus_heading',npt.north,npt.heading);contrast('nav_north_minus_aided',npt.north,npt.aided)
nh=n.pivot(index='pid',columns=['mode','heading'],values='rt');contrast('nav_aided_180',nh['north','180'],nh['aided','180'])
na=n.groupby(['pid','mode']).acc.mean().unstack('mode');contrast('nav_acc_heading_minus_north',100*na.heading,100*na.north);contrast('nav_acc_aided_minus_north',100*na.aided,100*na.north)
# Holm correction across all 10 reported inferential comparisons, explicitly post-hoc.
items=sorted(res['contrasts'].items(),key=lambda x:x[1]['p']);last=0
for i,(name,v) in enumerate(items):last=max(last,min(1,v['p']*(len(items)-i)));v['p_holm']=last
res['cell_fps']=f.groupby(['type','cue','size'])[['rt','acc']].mean().reset_index().to_dict('records');res['cell_nav']=n.groupby(['mode','heading'])[['rt','acc']].mean().reset_index().to_dict('records')

open('results.json','w').write(json.dumps(res,ensure_ascii=False,indent=2));print(json.dumps(res,ensure_ascii=False,indent=2))
```
